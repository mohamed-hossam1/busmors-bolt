# KPI Evaluation

## Method
- Translate the marketing objective into a small set of meaningful indicators and supporting diagnostics. Prefer an approved target or comparable historical baseline to an invented industry standard. Identify numerator, denominator, units, level of aggregation, population, time window, source and event definition for every reported KPI.
- Validate numeric types, signs, missing fields, duplicates, coverage, currencies and time windows. Use verified calculation tools, not mental arithmetic, for derived figures. A missing value is unknown, a recorded zero is zero, and division by zero is undefined. Do not round intermediate calculations prematurely.
- Select formulas only when the required data exists. Examples: CTR = specified clicks / impressions × 100; CPM = spend / impressions × 1,000; CPC = spend / specified clicks; cost per result = spend / matching results; conversion rate = specified conversions / eligible interactions or cohort × 100; ROAS = attributed conversion value / corresponding ad spend. Follower growth rate uses net change / starting followers. Explicitly label the chosen definition; platform-reported rates may differ. Revenue and cost must use compatible currency and attribution. ROAS is not profit or ROI.
- Compute aggregate rates from compatible totals, not unweighted percentages of unequal groups. Reconcile headline values with source totals or an independent calculation when possible. Report base counts, rounding, and meaningful percentage-point versus relative percentage changes. A zero baseline makes relative change undefined.

## Egyptian relevance
Use business-specific conversion milestones: qualified WhatsApp leads, confirmed orders, delivered orders, appointments or store transactions as supplied. Do not equate messages with sales. Clarify whether EGP revenue is gross, net of refunds, or delivered-order value. Never infer an offline sales total from social activity.

## Return and review
Return a concise KPI dictionary and value table with observed figures, formula inputs or references, period, target/baseline, comparison and limitations. Use null for unavailable or undefined values and explain why. Avoid blanket red/green thresholds or invented benchmarks. Recommend the next decision or missing measurement, not financial or accounting advice. If accurate calculation is unavailable, provide raw observations and mark derived KPIs unverified.
